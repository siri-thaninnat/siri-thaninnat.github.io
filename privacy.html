Privacy policy

Personal is a desktop configuration operated by siri-thaninnat to access the operator's own Google Drive through rclone and WinFsp. This policy describes that personal setup and this informational website.

Google data accessed and used

With the owner's consent, the desktop client accesses Google Drive file contents and metadata, including file and folder names, identifiers, sizes, timestamps, and checksums where available. It uses this information to list, read, create, update, move, and delete files as requested through the mounted drive.

OAuth access and refresh tokens are used to authenticate the desktop client with Google. This website does not collect Google passwords or implement a Google sign-in flow.

Storage and retention

OAuth tokens and configuration are stored in the owner's local rclone configuration. File data may be cached on the owner's computer, and operational logs may contain file names, paths, timestamps, and errors.

The configured VFS cache has a target maximum size of 10 GiB and a maximum unused age of 12 hours. These are cleanup settings, not a guarantee of immediate deletion: open files and pending uploads may remain longer. Log rotation limits each log file to 10 MiB and retains up to three rotated backups. OAuth credentials remain until removed or replaced by the owner.

Copies stored in Google Drive remain subject to the owner's actions and Google's retention and trash behavior. Removing a local cache does not itself delete the corresponding cloud files.

Sharing and disclosure

The desktop client communicates with Google's services to perform the owner's requested file operations. The operator does not sell Google user data, share it for advertising, or send it to AI model training services. The setup does not provide a shared application server or access for other users.

Files and credentials are not uploaded to this website or its source repository. The website is hosted by GitHub Pages. GitHub may process visitor connection data such as IP addresses under GitHub's privacy statement. The site adds no analytics scripts, advertising, cookies, or contact forms.

Security and owner control

Google API requests use HTTPS. Local configuration, tokens, logs, and cached files rely on the security of the owner's Windows account and computer; this setup does not add application-level encryption for those local files.

The owner can stop the mount, remove its Windows startup shortcut, revoke the app's permission through Google Account connections, and remove local credentials or cached data. Pending uploads should finish before cache or configuration is removed.

Google API data commitments

Personal's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

The operator is siri-thaninnat. Questions or requests may be submitted through the project contact page. This page is public; do not post private files, credentials, tokens, or sensitive personal information.

This policy will be updated if the setup's data practices change. The effective date appears above.
