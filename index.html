A personal desktop utility

Your files.
Your own computer.

Personal connects the owner's Google Drive to Windows as a mounted drive using rclone and WinFsp. It is intended only for the owner's use.

What the app does

The desktop setup lets the owner browse, read, create, update, and delete their own Google Drive files through Windows. It uses a local file cache to support desktop applications and repeated reads.

Why Google access is requested

Google Drive access is needed to list files and folders, read file contents, and save the owner's changes back to Drive. Google OAuth is used to obtain the owner's consent. Personal does not ask for a Google password.

Where the data goes

The desktop client communicates with Google Drive. Cached files, OAuth tokens, configuration, and operational logs are stored on the owner's Windows computer. This informational website does not connect to Google Drive or receive those files or credentials.
